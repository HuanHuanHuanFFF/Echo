## 实现与责任

- [evaluation.ts](../../src/evaluation.ts)：固定语料/标签校验、配置与代码指纹、预热、策略对照、事实覆盖、累计上下文核算、失败记录。
- [eval-cli.ts](../../src/eval-cli.ts)：本地/配置 API 模式与显式调用上限；API 用量由 embedding.ts 实际记录。
- [固定样本](../../evals/dataset.json)：10 篇 Agent 自编中文笔记、14 题（13 个有答案、1 个无答案）、24 项题目事实需求。
- [使用入口](../../README.md)、[配置契约](../design/configuration.md)、完整自定义示例与 MCP 标准客户端。

普通 CI 可运行全部本地评测和协议回归，不需要个人笔记或模型 key。
API 模式只索引固定 corpus，不使用配置里的个人 collections；查询 embedding 预热并缓存后，各策略复用。
记录的检索延迟不包含 API 准备与 MCP 启动/传输；累计预算包括规范请求/响应及实际文件补读请求/响应。
API 请求预算在发送前检查，失败保存 failure.json 和用量；没有记录的服务 token 不当作零。
