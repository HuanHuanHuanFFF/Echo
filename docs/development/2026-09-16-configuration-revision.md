## 实现约定

- 主入口 version=2，以 active 选择四类 ID；路径统一以主入口目录为基准。模型 key 保持环境变量引用。
- 策略为同名 .mjs 的完整固定实现；不传外部 options。加载时保存模块字节及声明资源的内容快照，查询过程不再次读取可变策略文件。内置标题切块/本地 ICU 分词通过固定的 helper 接口复用。
- 数据库保留不同策略的来源/切块表，以及依赖它们的 FTS、向量表。登记完整身份；可读表名只使用安全编码。成功同步才发布状态，未选中组合遇到来源变动明确失效。
- 旧配置不静默丢弃参数。可验证兼容的历史索引在迁移时复用；不兼容的配置明确要求迁移或同步，不伪装成功。
- 活动配置下一请求生效；在途请求保留开始时的完整快照。数据库路径和运行设置变化明确需要重启。缺失索引返回可执行恢复步骤，不隐式调用模型。
- 普通同步调用额度、旧索引清理、自动监听与写入型 MCP 工具不纳入。

## 验收证据

待随实现补齐配置/策略契约、实际表依赖、关键行为回归、真实 MCP/Agent 场景和双人审查结果。普通验证只使用隔离样本和临时数据库，不访问个人笔记或真实模型。
