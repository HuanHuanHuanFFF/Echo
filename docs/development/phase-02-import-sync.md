- [chunker.ts](../../src/chunker.ts)：标题感知默认规则、用户模块加载、范围及正文校验。
- [store.ts](../../src/store.ts)：sources/chunks/meta 与模式版本；source_id 在单个数据库内唯一。

## 身份与位置契约

缺 ID 时先生成 UUID v4 并写回；已有 ID 不变，大小写按同一身份处理；无效、非 v4、
重复 YAML 键、非法 UTF-8 或重复 ID 使本次同步失败，不覆盖旧索引。UUID 在整个数据库内唯一，多个集合不能复用。
保留原 frontmatter 的其他文本、正文、BOM 和换行；已有 block/flow mapping 均支持。
为避免身份经别名或复杂元数据泄漏，首版**整个 frontmatter 不进入切块或检索**，
不把其他元数据的搜索列为已实现能力。

引用行号按成功写回后的完整文件计数，1-based、两端包含。证据以 LF 展示，
CRLF/BOM 不改变行位置。仅连续原文范围可成为 chunk；外部模块不能跨过滤区、伪造正文或越界。

## 默认切块及重建

`echo-heading-lines@1`：ATX 标题层级、围栏代码中的伪标题排除；不跨标题 section。
保留原文整行，按 max_chars（默认 1000，64–100000）聚合，去掉块边缘空行；无重叠。
单行可以超过软上限；长代码可按原文行拆开，范围始终连续，标题路径保留所在 section。
不声称与旧 Java/Python 的 token/overlap 规则完全等价。首版不解析 Setext、引用链、远程文件。

[配置契约](../design/configuration.md)和源码定义实际参数。默认选项部分覆盖继承默认；
自定义模块接收自己的 options，导出 id/version/chunk。主模块字节、声明版本、配置共同组成指纹。
修改自定义模块的依赖时须提升 version；启动新进程，避免 ESM 依赖缓存隐藏变更。
模块/配置/内容变化重建相关 chunks；仅查询参数变化不要求重新切块。

## 同步可见性与恢复

使用 `BEGIN IMMEDIATE` 持有单写者事务，WAL 读者继续看到旧提交。全部配置集合扫描和切块完成，
再次核对文件清单和内容哈希后提交；任何异常或取消回滚整次索引更新。缺失集合目录视为错误，
不能当作空库删除。移除配置集合后执行 sync 会从该数据库移除其来源。

同数据库并发写者最多等待 5 秒后报 busy；崩溃时 SQLite 回滚，成功写入笔记的 UUID 保留，
下一次同步复用。原文与数据库不是跨文件系统事务：外部编辑器需在同步期间保持文件稳定，
写回前后检查可检测变动，但不提供与任意编辑器的原子锁协议。当前按显式 sync 使用，不自动监听。

扫描 .md 文件，跳过隐藏目录/文件、node_modules 和符号链接；单文件上限 10 MiB。
原文不进入 Git；此阶段只在临时目录执行写回。
