## 本版变更

- packing_mode 默认 preview，支持配置和单次覆盖；保留定位、均分正文预算、回收短块余量。whole 保留完整块，预算不足跳过整块并继续尝试后续候选。
- 新增 text_truncated、准确 preview_range 和响应生效模式；start_line/end_line 仍定位完整块，不能当作全部文字已返回。
- max_results 默认 20 且为配置专属上限；topk 默认 10。传统参数/Qasper 评测显式 whole，补齐运行身份校验；有界字符成本避免巨型 JSON 溢出。
- 具体实现及验证见[装箱记录](2026-10-06-budget-previews.md)，不回写历史评测，也不宣称 Agent 补读或作答质量已验收。

## 版本与升级

package.json、package-lock.json 和 MCP 服务版本同步为 0.2.0。安装包验收新增包版本与 MCP 握手版本一致的检查。采用 0.2.0 是因为默认正文返回行为变化并新增可配置模式。

已有调用方应检查预览标记后定向补读；若依赖全文块，配置 packing_mode=whole。旧 topk>20 需显式调大 max_results 或调小 topk。升级后重启 MCP，无须因本版装箱改变重新 sync；原笔记修改后的同步规则照常。init 不覆盖已有配置和说明。
