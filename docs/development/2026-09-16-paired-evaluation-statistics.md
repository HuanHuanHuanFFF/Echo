## 比较入口

```sh
npm run eval:compare -- --baseline /path/baseline-run --candidate /path/candidate-run --output /path/new-comparison.json
```

比较器读取两个 run 目录的 dataset.json、manifest.json、report.json、rows.jsonl。
要求题集原始字节/语料、实际请求和累计上下文预算一致；核对逐题/子题标签、结果日志和覆盖计数。
拒绝发布报告缺失、标签字节变化、预算不一致、重复ID、非法事实计数或已有输出。
输出须位于输入运行目录之外，解析真实目录后判断，避免通过目录链接写回运行资产。
原始逐题结果仍由各 run 保留，比较文件记录四个输入文件的字节SHA256和双方运行/配置绑定。

- 父题：必需事实覆盖率、证据齐全的可答题比例及候选减基准的差值。
- 子题：沿用父题 intent_group 分组，不能把一个问题拆成更多独立样本。
- 题型：每类单列；无答案非空返回、失败数量、累计上下文、延迟P50/P95和实际API用量单列。
- 部分失败：保留题目和实际结果，标为 diagnostic_incomplete，不能包装为完整验收。

每次命令只比较同一题集/场景，不把额外干扰复跑合进300题分母。
主实验各分库、混合库分别比较；可选70%/30%总汇需在完整标签冻结后另外生成，当前无跨场景总汇。

## 区间解释

采用成对 percentile cluster bootstrap：每轮抽取与原数据同样数量的独立意图组，
有放回地复制该组所有题目，并在同一次抽样中计算两方案差值。
默认10000轮、固定种子20260916，2.5%与97.5%分位采用线性插值。
同一组重复题和固定子问题仍共同抽取；不能用改写后的题数虚增置信度。

区间只针对该冻结样本与独立意图假设，不是p值、线上泛化保证或面试官认可保证。
只有一个提供可答分母的独立组时不计算区间；主指标仅从有可答事实的组抽样，总组数和可答组数分别记录；没有可答题时比率与差值为null；空分母不记作零，
有效轮数单独记录。少量独立组或偏置语料仍会限制区间解释。
检索证据覆盖不等于生成答案正确率，非空无答案结果不直接判成幻觉。
