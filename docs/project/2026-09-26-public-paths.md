# 发布材料中的本机路径

日期：2026-09-26。状态：用户已确认；当前分支实施。

用户要求所有对外材料中的本机目录脱敏。本约定适用于 README、设计/评测文档、样例、归档回执及评测脚本的路径常量，替代旧文档“使用当前工作区绝对路径”的约定。运行时 MCP 返回的真实文件定位、用户本地配置和私有原始实验文件仍按功能契约工作。

## 路径约定

- 仓库内文档/源码链接使用相对路径，移动或克隆仓库后仍可打开。
- 外部资料目录使用下表的角色占位符；不发布用户名、个人目录层级或固定磁盘上的项目位置。
- 安装示例使用 `/absolute/path/to/...` 等通用示例，并注明需要替换。JSON 中的占位符不是 Echo 自动展开的环境变量。
- 历史记录保留相对文件名、实验日期/ID、Git SHA 和原始测量值，避免丢失来源关联。

| 占位符              | 代表                         |
| ------------------- | ---------------------------- |
| `${REPO_ROOT}`      | 对应版本的 Echo checkout     |
| `${EVAL_ROOT}`      | 本地评测数据与产物根目录     |
| `${NOTES_ROOT}`     | 本地个人笔记根目录           |
| `${REFERENCE_ROOT}` | 外部参考仓库根目录           |
| `${CHECK_ROOT}`     | 使用者独立复验的临时工作目录 |

将占位符映射到自己的目录后再运行历史命令。两个原先隐含个人目录的脚本现在要求显式参数：

```text
node evals/freeze-product-comparison.mjs --dry-run --root RUN_ROOT --private-root PRIVATE_ROOT --public-root PUBLIC_ROOT
python evals/analyze-public-full-cap6.py PUBLIC_ROOT OUT --private-a-root REFERENCE_A --private-b-root REFERENCE_B
```

## 历史测量与字节边界

[脱敏清单](../evals/2026-09-26-path-redaction.manifest.json)记录每份固定 JSON/JSONL 快照的原始/脱敏 SHA-256、大小和基线提交。仓库文本哈希按 LF 形式计算，避免 Windows checkout 换行转换造成假差异；README 和可编辑 Markdown 的变更由 Git 保存，不被快照哈希检查锁定；外部使用者原收据的原始哈希直接针对收到的原始字节。

**脱敏副本不是原始运行输出。** 替换目录后，JSON 字符长度和文件哈希会变化。快照中的耗时、请求/响应字符计数、源版本及原始产物指纹仍是当时测量；不能用脱敏后的 JSON 长度重新解释原预算或宣称指标变化。既有数值、问题标签、证据正文与检索成绩不因本次清理重算。原始产物哈希用于定位历史输入，脱敏哈希用于验证公开副本。

新增[使用者复验记录](../evals/2026-09-26-agent-recheck.md)与[脱敏收据](../evals/2026-09-26-agent-recheck.receipt.json)，归档接口行为证据；原始临时目录不写入发布材料。

## 检查与范围

`npm run check:paths` 扫描受版本管理及未忽略的待提交文件，检查常见磁盘路径、用户 home 路径和 UNC 路径，并识别 JSON/JS 转义、百分号编码。报错只列仓库内文件及行号，避免 CI 日志再次泄露值。仅放行少量明确通用的文档/非法路径测试样例。这是文本检查，不是任意编码、二进制内容或全部个人信息的检测器。

该检查已接入 `npm run check` 和原 Windows/Linux CI；[回归](../../tests/public-paths.test.ts)覆盖扫描、脱敏副本完整性和显式目录参数。原文定位、索引内容、检索参数和模型调用行为不在本次修改范围。

本次清理当前发布分支的文件。未提交的其他工作仍由其原任务维护，发布时同样需要通过检查。Git 旧提交及历史 PR 差异仍可能展示原路径；清除它们需要另行决定重写历史，本次未执行。
