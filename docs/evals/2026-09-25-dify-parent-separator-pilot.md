# Dify 父块分隔符小范围对照（2026-09-25）

状态：仅完成 A/C 75 题探索性对照；其余私有范围与公开集因运行耗时过长而停止，未继续测试。本报告保留局部结果，不替代[全量产品对照](2026-09-24-echo-dify-results.md)，也不修改 Echo 默认配置。

## 问题与唯一变量

旧版 Dify 1.17.1 的层级切块先按父分隔符 `\n\n` 切开；短段不会再合并。A/C 语料中大量短段让返回的父块过小。本轮仅把父分隔符改为 `\n\n\n`，其余冻结值相同：父块 paragraph、上限 1024 字符、overlap 0；子块 `\n`、上限 512、overlap 0；qwen3.7-text-embedding 1024 维；Dify 加权混合向量 0.7／关键词 0.3、候选 60、不启用 rerank 或阈值；统一打包 top10、每篇上限 6、请求与结果合计 20000 UTF-16 字符。沿用原 50 道 A 题、25 道 C 题及固定子问题，不运行 Agent 答案生成。

语料、查询、标签逐文件 SHA 与旧版相同：A 为 150 篇／50 题（48 可答、125 事实），C 为 165 篇／25 题（25 可答、46 事实）。两个候选库使用全新的 Dify dataset、workflow、索引状态和仓库外私有实验目录。

## 同题结果

完整证据指全部必需事实的原文区间被返回证据覆盖；Hit@10 指至少一个单块覆盖必需事实。跨块合并可使完整证据成立而 Hit 不成立。上下文是每题请求＋返回 JSON 的平均字符数，不是模型 token。

| 范围／方案    | 完整证据@10 | 事实覆盖 | Hit@10 | MRR@10 | 平均上下文字符 |
| ------------- | ----------: | -------: | -----: | -----: | -------------: |
| A 旧 Dify     |       19/48 |   79/125 |  37/48 | 0.4263 |           2584 |
| A 三换行 Dify |       48/48 |  125/125 |  48/48 | 0.9201 |          10401 |

| C Echo 参考   |       25/25 |    46/46 |  24/25 | 0.8200 |          11298 |

A/C 合计完整证据由旧 Dify 25/73 提至三换行 73/73；Echo 在同一 73 道可答题也是 73/73。三换行明显改善此样本，但平均上下文相对旧 Dify 大幅增加；A 的新 Dify MRR 高于 Echo，C 则低于 Echo。A 另有 2 道无答案题，本轮未评价拒答能力。只测私有 A/C，不能推断其他私有范围、混合库或 QASPER／固定公开集，也不据此宣称整体产品优劣。

## 运行完整性与边界

- 旧实验保留原位。首批候选 v2 因实验磁盘用量跨越 Weaviate 97% 只读阈值，数据库虽标记完成，A 实际向量为 0/8085；该批没有进入评测。v3 使用新 dataset 重建，Weaviate 阈值改为 98%（当时实验磁盘尚余约 28 GB），且通过实际向量、文本、维度、模型缓存和原文映射审计。只读阈值是实验环境修复，不是召回变量。
