# 私有父题首次命中后的固定补读策略

日期：2026-09-26。状态：执行前冻结；本文件不含评分结果。承接[QMD 首次对照](2026-09-25-qmd-private-comparison.md)与[Echo 首次对照](2026-09-24-echo-dify-results.md)，仅处理其中保存的私有 200 道父题、A/B/C/D/混合五范围。保留 QMD 首次查询的 3 个错误，绝不重试或重新检索。

每题只看首次响应已选的结果，按原返回顺序去重文件并取前三个。每个文件以其第一次命中的位置为中心，从命中行前五行起，最多读 80 行；不足预算时，从末尾逐行缩短，直到预计完整调用和返回可放入预算。没有足够空间则跳过。无论是否已读到答案，都按这条规则继续；不读取标签来选择文件、行、调用次数或停止位置。Echo 用经 SHA 验证的冻结文件副本和原始行号做宿主读取；QMD 使用已安装 2.8.3 MCP 的原生 `get(file, fromLine, maxLines, lineNumbers=false)`。不调用 query/search/vsearch、embedding、rerank 或 query expansion。

三组各题的标准化累计预算均为 20,000 UTF-16 字符。先扣除首次对照所记录的标准化请求和响应字符；每次补读再累加 JSON 化的请求与响应，重复正文也计入。QMD 在发出请求前额外留出 1,024 字符，以容纳原生资源的可选上下文前缀；真实返回若仍超出预算，完整保留并标记超限，不裁掉返回文本。标准化计数不包含 MCP 协议封套；原生调用与完整返回另存于 Git 忽略的实验目录。评分对映射到同一冻结原文的重复片段做覆盖并集。

严格完整证据仍要求必需事实的标注原文行全部被实际返回文字覆盖。找到文件、关键词或相似段落均不算事实覆盖。首次响应与补读的逐题变化将独立评分；这是固定策略的取证补读，不是 Agent 自主决策或最新元数据版本重测。
