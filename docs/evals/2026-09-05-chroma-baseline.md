## 4. Q11：单个主题占满候选

原问题：

> Agent 调用一个有副作用的工具时，Router/Registry/Handler、状态机、审批暂停恢复，以及 State/Event Log/Trace 如何配合，让请求可控、可审计、可恢复？

| 排名 | 召回内容 |
|---|---|
| 1～8 | 同一篇 Router/Registry/Handler topic 的 Effect、Mechanism、来源说明、Problem、Design、Motivation、Boundary、Tradeoff |
| 9～10 | 审批 topic 的 Effect、Design |
| 未进入 Top10 | 状态机与 Guard、State/Event Log/Trace；完整审批恢复机制也不足 |

报告的四项评分需求为工具分发、审批暂停恢复、状态机与 Guard、State/Event Log/Trace。预期来源还列有副作用授权笔记，但它不是另加的第五个评分项。后续标签应保持需求与计数对应，部分覆盖单独记录。

状态机、Trace 和审批原文已在本会话核对存在。但**本地有原文不等于相关片段已正确入库**。诊断召回原因前，按 note_id/source_path 在 collection 中读取并核对缺失笔记的实际正文与哈希；当前资料不能排除索引同步问题。

## 5. 从原始结果补充得到的观察

以下仅统计 11 道可回答题的 110 个返回位置，可能包含跨查询重复片段，不是全库分布：

- 90 个位置的正文估算 token 数不超过 100。
- Q11 前八条来自同一篇笔记，正文估算 token 合计 447；不含重复标题前缀等完整请求开销。
- 按原判断标签，110 个位置中有 10 个被标为无效或不足，包含纯来源说明和跳转材料。
- 同篇不同章节可能互补，唯一来源数少本身不等于去重失败。跨层相同表述与同篇互补章节应分开处理。
- 短正文加重复标题可能影响排序，是待对照的假设，不能据此直接移除标题上下文。

标签有改进空间：Q11 的有效 ranks 包含较宽泛的 Effect/Problem。后续可区分主题相关、部分支持、充分支持，按必要证据点打标。Q12 的结论来自人工式证据核对，尚无生成模型拒答验证。

## 6. 优先验证的策略

| 策略 | 预期解决的问题 | 局限 |
|---|---|---|
| 扩大候选池 | 判断缺失文档是否只排在 Top10 之后 | 不保证找到缺失主题 |
| 文档分组＋组内少量片段 | 防止同篇内容占满外层名额 | 只能组织已召回文档 |
| 子问题独立召回 | 给状态机、Trace 等需求独立检索机会 | 增加模型调用和候选成本，需预算可比 |
| 导航／正文分流、父章节补读 | 减少来源说明和跳转占位，补齐互补章节 | 不以片段短为由删除关键定义 |
| BM25＋向量＋RRF | 验证明确术语是否补回遗漏材料 | 本样本尚未证明词项漏召回是普遍短板 |
| rerank | 将机制证据排到泛泛说明之前 | 不能补回候选池中不存在的内容 |

文档分组的算法、聚合键和边界集中维护在[检索设计草案](D:/CodingProject/echo/docs/design/retrieval.md)，此处只记录实验目的。

## 7. 下一轮小对照建议

先核实 Q11 缺失来源已入库，再固定题目、证据标签、语料、embedding 和最终返回 token 预算。以 Q11 加两道类似综合题，配 Q03、Q09 作互补证据回归；新题在查询前核对预期证据。

| 实验 | 变化 | 要回答的问题 |
|---|---|---|
| A | 完整问题，向量 Top40 | 缺失材料是否排在 11～40 位？ |
| B | A 加文档分组及导航片段处理 | 是否减少名额浪费并保留互补证据？ |
| C | 四个子问题各取 Top10 | 在最多 40 个原始候选名额下，是否提高覆盖？ |
| D | 同等总候选预算下 BM25＋向量＋RRF | 关键词通道是否提供额外证据？ |

数字是实验起点，尚未确定为 Echo 默认值。记录原始候选数、去重后数量、最终 token、模型调用和耗时；“各路名额之和相同”不等于计算成本相同。最好先测分组与导航处理的独立影响，再看组合效果。

候选覆盖足够后再单独测试 rerank、父章节读取；不要同时换切块、模型和所有检索步骤。指标以必要证据覆盖和完整问题比例为主，Hit@K 辅助，记录重复／无效内容占用与延迟成本。距离或 RRF 分数不作答案置信度。

未来迁移 Chroma → SQLite 后先核对同模型纯向量路径。HNSW 与新检索实现的差异不能记成 BM25 或 RRF 的收益。用于简历的结论需带样本范围、比较条件和实际测量，不从本轮 12 题推出普遍效果。
