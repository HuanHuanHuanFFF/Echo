# Agent 使用者独立复验

日期：2026-09-26。验证版本：`0673f0ada6dd8f7dc17147d7973eb89501e616f8`。
状态：使用者报告前三项接口问题关闭，本轮无阻断发现；完整 Agent 日常任务效果另行验收。

## 来源与边界

使用者在临时 Markdown 副本中重新构建并启动标准 MCP 客户端，独立完成36次调用、47项检查。主线程读取[归档收据](2026-09-26-agent-recheck.receipt.json)，核对提交、调用记录及当时构建文件 SHA-256 一致；未将这次收据核对描述为主线程重新执行36次调用。

使用者另报告28项相关回归通过；本 JSON 仅包含36次调用和47项检查，不包含那28项测试的运行日志。模型部分失败保留成功证据另有既有[集成回归](../../tests/mcp.test.ts)覆盖。该复验不重新评价真实向量质量或最终回答质量。

归档副本已按[发布路径约定](../project/2026-09-26-public-paths.md)替换目录；原始与公开副本字节哈希见[脱敏清单](2026-09-26-path-redaction.manifest.json)。以下字符数保留原始调用测量，不从脱敏副本重算。

## 结果

| 范围       | 记录支持的行为                                                                               |
| ---------- | -------------------------------------------------------------------------------------------- |
| 新鲜度     | 默认 unchecked；内容修改、插入行、新增、删除、移动可识别；同大小且恢复 mtime 后仍识别修改    |
| 失败与只读 | 无效 UTF-8/超大小为 unknown；索引原本就绪时 needs_sync=null；检查不写笔记、数据库或新增 UUID |
| 同步与定位 | 同步后正文、行号、章节范围正确；移动后路径更新，来源身份保留                                 |
| 参数与过滤 | 类型/范围可发现；未知 collection、绝对/越级/UNC 前缀明确失败；合法空范围为正常空结果         |
| 子问题     | 独立归属、共享证据去重、只覆盖显式参数通过                                                   |

同进程、相同短样本与查询，两个模式均返回相同数量证据：

| 场景       | 默认响应字符 | 诊断响应字符 | 默认相对诊断减少 |
| ---------- | -----------: | -----------: | ---------------: |
| 单问题     |         1135 |         2050 |            44.6% |
| 两个子问题 |         1203 |         2149 |            44.0% |

这只是短样本响应字符开销对照，不代表所有查询、累计上下文或 token 都减少相同比例。

- 1200字符预算：默认返回2条证据，诊断返回0条，支持“精简发生在预算装箱之前”。
- 256字符预算：默认响应129字符，明确 empty_reason=budget、limits=[budget]。
- 无候选与数量上限导致零证据可分别识别。

本次证据支持关闭参数/范围发现、原文新鲜度表达、正常输出与零证据反馈这三项接口问题。综合问题、补读、引用、证据不足时停止及累计调用成本，仍属于 Echo 与宿主 Agent 的联合任务验收。
