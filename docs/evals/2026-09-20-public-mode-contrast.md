# 公开固定片段：纯向量、BM25与混合的事后对照

日期：2026-09-20。状态：2302题的单路排名重评分与48次真实缓存模式probe完成，两位Luna/max独立复核通过。承接用户“纯向量和混合后，看看要不要调权重”的请求。本轮只补诊断，不增加权重档、不修改默认，不覆盖[原全量结果](2026-09-20-public-full-results.md)。

## 结论

**值得验证较低BM25权重，但不支持现在统一降低默认。** 当前权重0.5/1在LangChain有明确收益，在Du造成前排排序退化，在Godot没有稳定净收益。不能用一个数据集的结果决定所有个人知识库的默认。

- LangChain：混合RRF30的α-nDCG@10比纯向量高4.25个百分点，95%区间[+2.36,+6.17]；Coverage@20与Recall@50也提高。
- Du：纯向量nDCG@10为86.70%，高于混合RRF30的81.77%和RRF10的84.16%；两档混合相对纯向量的前10指标差值区间都为负。此前84.16%描述的是混合系统，不能直接用它评价embedding模型本身。
- Godot：纯向量与两档混合的主要差值区间均跨0。切回纯向量不会在现有结果中填补与强公开参考的差距。
- 仍未测0.25等中间权重；纯向量与0.5混合两个端点不保证中间参数单调改善，更不证明0.25最优。

候选数允许不足上限：Du有1/2000题的BM25仅返回3条，其他题为60条，平均59.9715；dense均为60条。48次模式probe为每库固定前8题，未覆盖这道特殊题，但全量静态名次/数量检查已覆盖。

这是**看过原公开结果后的事后分析**，不算新留出集、不增加独立题数，不根据结果修改冻结标签。四种排名共9208份逐题计分，其中4604份单路排名新补，4604份混合排名复用原结果。

原混合输出保存了所有正权重候选的两路名次，因单路分数1/(k+rank)随rank严格递减，可恢复完整单路排序。逐题检查名次1..N连续、候选数一致、ID唯一，并核对从RRF30和RRF10恢复的两路顺序完全一致。阈值与候选深度保持原样，不能将其称为无阈值全库向量排名。

## 要不要调权重

本轮支持**补一个较低权重的单变量验证**，尚不支持直接改默认。若继续，先固定当前默认RRF30，仅比较BM25 0.5→0.25，dense始终1；候选、阈值、输入与三个数据集保持不变。先看Du能恢复多少，再看是否损失LangChain的已验证收益，避免按单库选择通用默认。RRF10成绩作为独立历史条件保留，不同时变化RRF和权重。

已有[个人最终200题](2026-09-18-final-four-arms.md)中混合179/196、纯向量178/196，优势很小；[历史开发权重实验](2026-09-18-rrf10-bm25-combinations.md)也未显示降低权重稳定提升完整证据。这些是不同语料与打包条件，不能替代本轮公开排名比较，也不在本轮继续调私人最终集。

0.5是RRF名次分数乘数，不代表BM25占50%结果。是否改产品默认，要在新权重实际结果出来后另作决定；本轮保留原设置。
