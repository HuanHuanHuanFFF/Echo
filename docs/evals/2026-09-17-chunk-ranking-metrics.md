## 指标口径

使用实际交付给Agent的结果数组顺序；K=1/3/5/10均从原topk10结果取前缀，没有重新检索、重排或改变预算。子问题结果经过运行时轮转合并，并非按全局RRF分数重排的单列表；仍以父题计一次。少于K块时使用实际块数，未返回部分不补分。

标准Recall衡量相关项中被召回的比例；MRR取每题首个相关结果名次的倒数再平均。[Stanford IR教材](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-unranked-retrieval-sets-1.html)；[NIST trec_eval 的 reciprocal rank 实现](https://github.com/usnistgov/trec_eval/blob/main/m_recip_rank.c)。本评测使用固定事实锚点，以下明确相关性单位，避免把文件命中和完整事实混用：

| 指标                       | 本文定义                                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 严格单块Hit@K              | 前K块中至少一个块独立、完整覆盖任一必需事实的允许原文锚点，题目记1，否则0；表中同时给题数分母                             |
| 严格单块MRR@K              | 按上一行的单块相关性，首个相关块名次为r且r≤K时记1/r，否则0，再对可答父题平均                                              |
| FactRecall微平均           | 前K块共同覆盖的必需事实总数 ÷ 所有题的必需事实总数；同一事实在不同题出现按题目需求分别计数                                |
| FactRecall宏平均           | 每题先计算覆盖事实数/必需事实数，再对可答父题平均；每题权重相等                                                           |
| 完整题（CompleteEvidence） | 一题的全部必需事实已由前K块共同覆盖；不是答案生成准确率                                                                   |
| 前缀任一事实Hit            | 允许前K块拼接，只要完整覆盖至少一个必需事实即命中；可能高于严格单块Hit                                                    |
| 前缀首事实RR均值           | 首次由结果前缀拼齐任一事实的前缀长度r，取1/r再平均；对应旧报告first_fact_reciprocal_rank，是自定义指标，不冒充严格单块MRR |

一个事实允许多个OR替代锚点，完整覆盖其中任意一个就算覆盖；锚点所有非空行必须在实际返回文本和对应原文行号中出现，允许多块共同覆盖。空行只作格式。不会用标题metadata、文件名或未返回候选补事实。

严格单块相关性是从现有事实锚点推导的二值标签，不是人工穷尽标注的全部相关chunk。未计算标准chunk Recall、MAP或nDCG：当前没有适合这些指标的完整chunk相关集合与理想排序基准；二值标签本身并不阻止nDCG计算。这里的FactRecall衡量固定事实覆盖，不冒称标准文档Recall。

## 已标注来源指标：只作辅助

相关来源集合取本题全部允许锚点的文件并集。仍按前K个chunk取前缀，再对其中的来源去重；不是取前K个不同文件。即使某块未含答案，只要来自已标注文件，来源Hit/MRR也会给分。因此它们不能替代上面的证据指标。

OR替代也计入来源分母：某事实可由3个文件中的任一个支持，取回1个即可令事实Recall=1，但来源Recall只有1/3。95题累计150项题目来源需求（A62/B26/C16/混合46），不是150篇独立文件。现有来源标签不穷尽所有潜在相关文档。

## 无答案、成本与解释边界

5道无答案题单独统计，三策略均5/5返回非空，不进入95题的Hit、Recall、MRR分母。这不代表系统具有无答案识别能力，也不等于Agent必然生成错误答案。

100题原运行的请求+完整JSON累计字符分别为heading 1106071、原八股1104283、新综合1162737。相同预算上限不等于实际上下文消耗相同；K相同也不代表块长度或有效文本量相同。新综合比heading多5.12%的实际累计字符，需与早期排名一同考虑。

这些是同一批已多次用于开发的AI标注/复核题上的事后指标；不是新的独立样本、人工金标准或最终200题结果。没有据此更换默认策略，也没有重新调参、比较子问题拆分或运行最终集。

## 复现与核验

脚本：[summarize-chunk-comparison.mjs](../../evals/summarize-chunk-comparison.mjs)。它只读取原运行保存的dataset、quote锚点、返回原文、报告和哈希清单；不依赖当前个人语料路径或模型key。输出仅含数值与指纹，不含题目、笔记、具体源文件名或凭据。

```powershell
node evals/summarize-chunk-comparison.mjs --self-test
node evals/summarize-chunk-comparison.mjs "${EVAL_ROOT}/2026-09-16/evidence/structure-ab-2026-09-17-v3" "<新的输出文件.json>"
```

输出文件必须不存在；已有报告不会覆盖。输入仅支持本轮三策略、四库、成功完成的固定运行，不把它作为新的通用评测引擎。

核验记录：

- 原交付清单绑定的56个产物、plan指纹、12份dataset指纹均一致，三个策略在每个库使用相同题库。
- 300行逐题完整事实集合、前缀首事实RR，以及12份原报告的题数、事实数、完整覆盖、无答案统计全部复现。
- 主线程与Luna/max子线程采用独立代码重算；已共有的Hit、宏/微Recall、前缀首事实RR、来源指标逐库逐K核对。
- 收尾完整检查 npm run check 通过：格式、类型、123项测试通过/1项原有跳过、构建通过；文档相对链接与脚本SHA验证通过。
- 脚本7组隔离断言覆盖第三名首次命中、K截断、跨块拼齐、OR替代、空行、返回文本不符、少于K/空结果、无答案分母和无效锚点；零外部调用。

重算代码SHA、输入指纹与核验数量见机器可读统计中的provenance。原始结果仍保留在E盘；本篇与统计摘要进入仓库。
