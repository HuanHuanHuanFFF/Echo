## 下一轮开发参数实验（运行前固定）

依据上述真实开发结果，保持两种chunk、模型、语料、100开发+20同题、所有固定子问题和12000字符预算；每次只改当前hybrid的一项：

| 配置ID      | 唯一数值变化                       | 待验证问题                                         |
| ----------- | ---------------------------------- | -------------------------------------------------- |
| tune-wgt-05 | bm25_weight 1→0.5，dense_weight仍1 | 混合库是否因较强词面分量丢失dense已覆盖的证据      |
| tune-src-03 | max_chunks_per_source 2→3          | 是否改善同源事实被切成多块的覆盖，同时观察跨源挤占 |
| tune-rrf-10 | rrf_k 60→10                        | 更强调两路前列候选后，是否改善而不扩大其他库退化   |

三个召回ID与基线chunk-ab-v1等长，避免仅ID长度改变返回预算。三项不做笛卡尔组合，不按每库分别择优。
