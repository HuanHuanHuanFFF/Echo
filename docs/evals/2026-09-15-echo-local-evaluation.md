# Echo 本地固定样本评测

日期：2026-09-15。状态：**仅本地 BM25，真实 embedding 默认组合仍未验收。**

> 修订提示：本版中位延迟使用了上中位值，统计已在 [R2](2026-09-15-echo-local-evaluation-r2.md) 修正并重跑。原始证据和覆盖结果保留有效。

## 语料与方法

10 篇 Agent 自编中文笔记、14 题，其中 13 个有答案问题共 24 次事实需求，另有 1 个无答案问题。不是个人知识库、盲测或全库质量测试。原文与标签见 [dataset.json](../../evals/dataset.json)。
每题累计预算为 8000 个 UTF-16 字符，包含搜索请求/响应、补读请求/响应；不是 tokenizer token 数。API 调用为 0，未生成模拟向量。
同一 profile 内比较来源限制时固定语料、切块与其他召回参数；比较默认和自定义 profile 时只改变切块模块。补读方案给搜索约 65% 预算，余量用于真实文件章节读取，变化项单独记录。

## 结果

| 切块方案 / 策略                  | 任意事实命中 | 完整覆盖 | 事实覆盖 | 累计上下文字符 | 中位引擎 ms |
| -------------------------------- | ------------ | -------- | -------- | -------------- | ----------- |
| 默认 / bm25_default              | 13/13        | 12/13    | 23/24    | 57519          | 3.22        |
| 默认 / bm25_unrestricted         | 13/13        | 13/13    | 24/24    | 59812          | 3.03        |
| 默认 / bm25_with_host_read       | 13/13        | 12/13    | 23/24    | 67257          | 3.22        |
| 自定义候选 / bm25_default        | 13/13        | 13/13    | 24/24    | 57969          | 3.52        |
| 自定义候选 / bm25_unrestricted   | 13/13        | 13/13    | 24/24    | 58025          | 3.12        |
| 自定义候选 / bm25_with_host_read | 13/13        | 13/13    | 24/24    | 67397          | 3.13        |

默认参数：max_chars=1000、topk=8、每篇上限=2、BM25 候选=60、标题权重=2。unrestricted 将每篇上限改为 100，仍受 topk 与最终预算约束。

默认方案的 Q10 缺审批恢复事实：纯父标题占用了同篇名额。放宽单篇上限补齐了事实，但同篇占位增加；这个样本不支持“来源限制必然提高覆盖”的结论。
自定义候选不让纯结构父标题单独占位，Q10 因而补齐。它保留子章节的标题路径和原文范围，但此结果只支持本地小样本，尚未替换默认 hybrid 规则。
所有策略在无答案题仍返回片段；这是检索非空，不是生成了错误答案，也不能据此宣称具备可靠拒答能力。
毫秒数据是单次本机进程内检索的中位数，不含 MCP 启动/传输；样本很小且无统计置信区间，不作速度优劣结论。
