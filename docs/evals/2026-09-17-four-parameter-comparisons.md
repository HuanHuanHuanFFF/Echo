## 确实可配置：预算与其他召回参数

四项都已由[retrievalSchema/retrievalOptions](../../src/config.ts)支持：召回profile持久保存默认值，MCP echo_search 单次overrides优先。
例如一次查询可以这样指定返回预算：

```json
{
  "query": "需要检索的问题",
  "overrides": { "max_context_chars": 16000 }
}
```

这个配置项限制完整返回业务JSON，合法范围256–100000字符。评测报告的预算包含规范请求＋返回业务JSON，脚本先扣请求占用，再把剩余额度作为该override；不含MCP传输封装、系统提示或宿主其他上下文。单位是UTF-16字符串长度，不能直接当作模型token数。
[评测请求扣额](../../src/retrieval-evaluation.ts)与本轮覆盖测试是依据。

预算组用同一个12000/16000选择，同时派生profile响应上限、评测总额度与扣除请求后的返回额度。这样16k不会被旧的12k响应上限卡住；这是一个预算变量的关联约束，其他查询参数没有变化。
