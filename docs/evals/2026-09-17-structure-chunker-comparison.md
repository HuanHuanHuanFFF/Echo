## 结论

在相同召回设置下，heading完整覆盖90/95，新综合策略89/95，原八股段落策略83/95。
新策略在个人八股达到28/28，但课程和混合各比heading少1题；事实总覆盖217/226，低于heading的220/226。
新策略使去重开发语料块数减少40.48%，但100题累计实际上下文字符增加5.12%。因此不能宣称整体优于heading，也不据此替换默认。
这是整套切块规则的对照，不把差异归因于某一个内部阈值、标题合并或overlap。

## 三套切块规则

| 策略                     | 长度与边界                                                                                    | overlap                                      |
| ------------------------ | --------------------------------------------------------------------------------------------- | -------------------------------------------- |
| heading-1000             | 标题分节，整行累积，1000字符软上限；保留标题正文                                              | 无                                           |
| bagu-paragraph-800-lines | 标题/段落，估算token阈值300/800/1000；标题路径保留在metadata                                  | 同节内目标80字符、整行对齐                   |
| markdown-structure-v1    | 完整结构单元，目标1000/常规最大1500字符；同父标题下相邻短叶子小节≤200字符可合并；超长单行例外 | 仅单个超长单元被迫拆分时，目标80字符整行重叠 |

新策略保留标题正文与所有非空原文行，不补围栏、不重复表头。超长标题的展示路径按现有2000字符上限安全截断，原文不截断。
ATX/Setext、顶层围栏、缩进代码、管道表格、连续列表/引用在声明范围内；完整CommonMark/GFM嵌套语义不是本轮承诺。
