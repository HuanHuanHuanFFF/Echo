## 固定条件

| 项目         | Echo A                                                                                                                    | Dify hybrid                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 版本与切块   | `markdown-structure-v1@1.0.1`，标题/段落结构切块                                                                          | Dify 1.17.1 原生父子切块：parent 最多1024、child 最多512 Python 字符，overlap 0 |
| 词法与融合   | ICU-zh；MiniSearch 7.2.0，无匹配词数量乘数；k/b/d=1.2/0.7/0.5；BM25/向量权重0.5/1；RRF k=10；标题权重2；最低向量相似度0.3 | 原生 weighted hybrid：向量0.7、关键词0.3；原生 top_k=60；无重排和分数阈值       |

两边使用同一个 `qwen3.7-text-embedding` 1024维模型和冻结语料/问题。完整文档共同适配层按冻结子问题顺序轮转，来源和正文去重，`topk=10`、每篇最多6块、请求加响应上限20,000 UTF-16字符，整块放不下则跳过；这些是**本轮比较条件**。产品默认仍是每篇3块。私有题没有 Agent 生成答案，QASPER按目标论文过滤。FreshStack 与 Du 使用官方固定单元，不重切、不用完整文档打包；其原生候选上限不同，不能把固定库结果解释为切块胜负。
