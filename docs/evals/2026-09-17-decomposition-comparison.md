# 新综合切块：固定子问题与完整父问句对照

日期：2026-09-17。状态：两组真实运行与主线程核验完成，两位Luna/max独立复核通过。
本轮仅使用markdown-structure-v1，产品默认chunk未改；这是开发集对照，不是最终200题验收。

## 结论

当前数据支持保留原有固定拆分：在真正改变输入的33题中，完整题从不拆分21/33提高到27/33，事实覆盖从91/113提高到104/113。
按题比较，拆分多完整覆盖7题，也使1题退化；另有1题虽未完整，但多召回2项事实。共8题事实覆盖更好、1题更差、24题最终事实集合相同。
拆分的主要收益是多目标事实更齐全：严格单块Hit@10两组均33/33，MRR@10只有0.9091对0.8990。不能仅靠Hit/MRR看出此次多事实覆盖差异。

完整问句也有优势：K=1事实覆盖45/113对44/113，首块完整题2/33对1/33；A库首个事实出现更早。本轮不支持“任何问题都应该拆分”的结论。

## 范围与唯一变化

依据用户2026-09-17新要求，仅对新综合策略比较输入形式。本轮替代[小范围排查计划](../project/2026-09-17-small-scope-retrieval-investigation.md)中旧heading/topk8/每篇2和先6题的实验设置、暂不执行状态；承接[当前100题综合策略基线](2026-09-17-structure-chunker-comparison.md)。历史文档与标签保留。

- split：保留冻结子问题；有子问题时只发子问题，没有时发完整原问句。
- parent：在独立实验副本中只删除subquestions，改为发送同题原始完整问句；不改写问句或加入答案线索。
- 两组各跑同一开发100题，共200次父题执行、100个独立父题。主分析33道原有拆分题/68个固定子问题；其余67题作为相同输入的稳定性对照。
- 33题全部可答；完整100题包含95可答+5无答案。5道无答案单列，不进入Hit、Recall、MRR分母。
- 本轮不包含其他chunk、参数组合、原句+子题、子题顺序改动、动态Agent拆分或最终200题。

## 稳定性与模型波动

67道不改变输入的对照题，两组请求完全一致，最终返回chunk的身份、顺序、正文、定位及事实集合全部一致；其中62道可答题均保持完整覆盖，5道无答案仍全部非空。
但不是所有数值都逐位一致：只有21/67的完整结果JSON相同，37/67的累计字符完全相同；406处相似度数值不同，最大绝对差0.0002089143。少量dense_rank、RRF值、候选/排除计数也变动，未改变这67题的最终证据及覆盖。

这说明本次相同输入的结果覆盖稳定，但不能保证远程模型或浮点计算完全确定。因未额外保存查询向量，不能仅凭日志把数值差异唯一归因于服务端。
本轮split与上轮split相比，100题事实集合完全一致，96题返回证据完全一致；其余B-D18、C-D07、mix-dev-004、mix-dev-010有返回内容或顺序变化，未改变本轮报告的总体事实结论。

只读[稳定性审计脚本](../../evals/audit-decomposition-results.mjs)保留所有差异计数，不用“完整JSON不同”冒称答案证据不稳定，也不隐去数值波动。
