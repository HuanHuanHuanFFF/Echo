## 唯一变化与范围

- split：保留原冻结子问题；有子问题时只发子问题，没有时发原完整问句。
- parent：在独立实验题库副本中只删除subquestions，改为发送同题原始完整问句；不改写问句，不加提示或答案线索。
- 两组各跑同一开发100题，200次父题执行；主分析原来含拆分的33题/68子问题，其他67题作相同输入的稳定性对照。
- 题目、语料、父题事实与允许证据完全相同。5道无答案题独列，不进入可答命中/Recall/MRR分母。
- 不运行最终200题，不再比较其他chunk、权重、来源配额、原句+子题组合或子题顺序变化。

## 固定设置

| 项目          | 值                                                                             |
| ------------- | ------------------------------------------------------------------------------ |
| chunk         | markdown-structure-v1，直接只读复用原四个索引                                  |
| 语料          | A150/B22/C165；混合为337篇并集                                                 |
| 模式、模型    | hybrid；qwen3.7-text-embedding，1024维；无rerank                               |
| embedding调用 | 原DashScope URL、batch8、timeout30000ms、send_dimensions=true、空文档/查询前缀 |
| 分词          | icu-zh、zh-CN，无自定义词典                                                    |
| 权重          | BM25 0.5 / dense 1，标题2                                                      |
| 候选与融合    | BM25 60 / dense 60，RRF k=60，相似度阈值0.3                                    |
| 返回配额      | topk10、每篇最多3；全父题共享                                                  |
| 总预算        | 每父题规范请求+完整业务JSON≤12000 UTF-16字符                                   |
| 运行时        | 原E盘 b454686，代码逐文件哈希核对                                              |

两组的请求长度、子题归属元数据、候选路数会随输入结构变化，因此响应可用空间和实际字符数可能不同；这是当前拆分流程的整体效应，不额外给子题独立配额。
不把这一轮差异唯一归因于子题语义、轮转顺序或预算，也不外推成所有Agent拆分方法的好坏。
